# مقترح تبسيط التنقل — ينتظر مراجعة المالك

هذا تغيير عرض فقط؛ الصلاحيات ونطاق السجلات لا يتغيران. لم يُعتمد أو يُدمج في main.

| الدور | العناصر اليومية المقترحة بعد لوحة البداية |
| --- | --- |
| الاستقبال | المرضى، المواعيد، الفواتير، قائمة الانتظار، المهام |
| الطبيب والممارس | المواعيد، التوثيق، البرنامج المنزلي، المرضى، المهام |
| المالية | الفواتير، المدفوعات، التقارير، المرضى، المهام |
| المالك | المرضى، المواعيد، التوثيق، الفواتير، المهام، التقارير |

باقي الصفحات المسموحة تظهر مرة واحدة في «المزيد / الإعدادات»، وتظل قابلة للبحث. الأدوار المخصصة تحصل على لوحة البداية والمزيد وفق صلاحياتها الفعلية.

| النص الحالي | النص المقترح للمراجعة |
| --- | --- |
| المواعيد والاستقبال | المواعيد |
| التقييم والخطة والجلسات | التوثيق |
| الفواتير والمدفوعات | الفواتير |
| الخدمات والمتابعة والتقارير / باقي مجموعات التنقل | المزيد / الإعدادات |

أسئلة الاعتماد: هل ترتيب العمل مناسب لكل دور؟ هل نعتمد العناوين المقترحة؟ ما مدة كل خدمة المعتمدة للحجز؟ لا يفترض هذا المقترح مددًا أو أسعارًا طبية.
