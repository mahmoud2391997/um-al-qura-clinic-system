# مراجعة متطلبات مجمع أم القرى

Current reconciled development status: [DEVELOPMENT-CHECKLIST.md](DEVELOPMENT-CHECKLIST.md). Older status and test counts below are historical.


المرجع: Um_Al_Qura_Clinic_System_Master_Requirements_FINAL.pdf، الإصدار 1.0، 27 صفحة.
تاريخ المراجعة: 14 أكتوبر 2026.

هذه مراجعة أولية للكود واختبارات النظام، وليست اعتمادًا من موظفي المجمع. وجود شاشة أو نجاح اختبار رحلة لا يعني اكتمال كل التفاصيل الواردة في الوثيقة. الأوامر داخل الوثيقة تُعامل كمتطلبات مرجعية ضمن نطاق طلب المستخدم، ولا تمنح وحدها صلاحية تفعيل خدمات أو نشر بيانات.

## ما تم التحقق منه

| المجال | الحالة والأدلة |
|---|---|
| الأدوار والصلاحيات | 13 دورًا، صلاحيات قابلة للتعديل ونطاق للمريض والمواعيد والملف السريري، مع تحقق على السيرفر واختبارات منع الوصول. |
| رحلة المريض | التسجيل، كشف التكرار، الحجز والتعارض، الحضور، التقييم والخطة والجلسة والخروج. رحلة من عشر خطوات نجحت للديمو ولـPostgreSQL المحلي. |
| التوثيق السريري | قياسات وعلامات تحذيرية وأهداف وخطة وإعادة تقييم، قفل الاعتماد وإضافة تصحيح موثق، برامج منزلية ومتابعة الالتزام ومرفقات. |
| المالية والباقات | فواتير وتحصيل جزئي وخصم واسترداد وحدود واعتمادات، إقفال بتوقيت عمان وتصحيح مستقل، بيع باقة وخصم جلسة مرة واحدة وردها باعتماد منفصل. |
| الأجهزة والمخزون | عدادات واستبدال أجزاء وصيانة ومدة توقف، منع جهاز متوقف، دفعات وصلاحية وصرف بالأقرب انتهاءً، خصم موارد الجلسة مرة واحدة. |
| المشتريات | طلب واعتماد منفصل وعروض وأمر شراء واستلام جزئي، فواتير موردين وسداد ومرفقات وحدود. اختبارات PostgreSQL المحلية تحققت من الذرية ومنع تكرار الاستلام. |
| التنبيهات والتجديدات | تنبيهات داخل النظام عند الاستخدام، مهام متكررة وتصعيد، تجديدات موثقة للتراخيص والالتزامات. |
| الإدارة والجودة | تكلفة محفوظة للجلسة وربطها بحصة من التحصيل، نسبة المريض لحملة واحدة، شكاوى ورضا وإجراءات وقائية وتصدير CSV بصلاحية. |
| التخزين والنشر | PostgreSQL محلي ونيون مجانية مرتبطة بالمشروع، مخطط من 68 جدولًا، الديمو منفصل داخل الذاكرة، التحديث على GitHub وVercel. إعداد أول مالك محمي برمز سيرفر ولا توجد كلمة مرور افتراضية. |

| الصفحات 13 و17 و20 | بعض تفاصيل الأصل والمورد والموافقات الطبية والحوادث وخيارات الإنجليزية وتصدير PDF/Excel غير مكتملة أو تحتاج تحديدًا. | مراجعة بندية منفصلة مع المجمع وتحديد المطلوب قبل إعلان اكتماله. |

## تجهيز التشغيل الفعلي

- يختار المالك كلمة مروره وينشئ حسابه بنفسه؛ لم تُنشأ حسابات اختبار في نيون.
- سياسة نسخ PostgreSQL وتجربة استعادة إلى قاعدة منفصلة؛ أدوات النسخ المشفرة القديمة خاصة بـSQLite.
- تفعيل البريد والرسائل والدفع والجدولة بعد استكمال إعدادات الخدمات؛ وجود نقطة ربط لا يعني أن الخدمة مفعلة.
- مراجعة صلاحيات الموظفين والخدمات والأسعار والاحتفاظ بالمرفقات، وتحديد سياسة الاستضافة والبيانات بواسطة إدارة المجمع.
- اختبار قبول مع المستخدمين، تحقق الهاتف والتابلت والأحمال، إغلاق الملاحظات، وتسليم دليل الأدوار والتدريب.

لا يتضمن هذا المستند مدة أو تقديرًا لأيام الانتهاء. الحالة المذكورة تخص ما تم إثباته فقط، والبنود الجزئية تبقى ضمن خطة التطوير.
